Image tags

Every picture in Original text is listed once, even when it appears several times. Change a number if it is wrong, then press Insert tags to write it beside every copy of that picture. Giving two pictures the same number merges them. Numbers are remembered in this browser, so the same picture gets the same number in every tab and in every new text.

Keyboard shortcuts

Click a shortcut, then press the key combination you want. Shortcuts are saved in this browser profile on this device. Browser-reserved shortcuts may still be handled by the browser or operating system.

Define Phrases

Stored in this browser. "Apply phrases" swaps them in the comparison result only; your two input texts never change. Matching follows the Case sensitive switch. The number in brackets on the buttons is how many matches were found in the result. Use Export and Import to move your phrases to another browser or share them with someone.

Capitalize words in Compared text

Enter words or phrases separated by commas. Matching is case-insensitive. Use CAPITALIZE MATCHES in the Compared text toolbar to capitalize every matching whole word or phrase in Compared text only.

Define Styles

              
Set a style name and one or more words or phrases. Separate targets with commas or new lines. Each Apply button adds tags only in Compared text. Matching is case-insensitive. For a style named cat, a match becomes _style_cat_[cat]. Original text is never modified. These rules are separate from Define Phrases.
